# 松野 フィールド地図

https://wata909.github.io/matsuno/

愛媛県北宇和郡松野町を初期表示にしたスマホ向けWeb地図（PWA）。愛媛県・高知県のCS立体図に、地理院地図・主題図・GNSSログ・範囲保存（オフライン）を組み合わせています。
[wata909/fieldmap](https://github.com/wata909/fieldmap)・[wata909/nishiawakura](https://github.com/wata909/nishiawakura) と同じ仕組みです。

iPhone の Safari で開き「ホーム画面に追加」すると、アプリのように使えます。

## 画面下のツールバー
- **地図**：背景（標準・淡色・写真）＋ 地形（CS立体図・陰影起伏・色別標高）＋ 主題図1つ（地質・植生・地形分類・古写真）＋ 重ねるデータ（GNSSログ・筆ポリゴン・人口・旧市町村界・読込データ）
- **現在地**：現在地を表示し続ける
- **記録**：GNSSログの開始／停止、軌跡表示、GPX・GeoJSONで保存、消去（記録中は画面ロックを防止）
- **集水域**：💧を押して地点をタップ → 地理院DEM（10m）から上流の集水域を計算
- **保存**：今の画面の範囲を端末に保存（圏外で使えるように）。CS立体図も保存できる（1回1,500枚まで）
- **その他**：共有URL、文化財総覧WebGISへのリンク、GeoJSON読込、ZIP書き出し（GNSSログも入る。植生図・CS立体図タイルは不可）、出典

## CS立体図
松野町は愛媛県、南隣の四万十市などは高知県なので、両県のタイルを「CS立体図」1つのスイッチでまとめて表示します。

| | 愛媛県 | 高知県 |
|---|---|---|
| データセット | [愛媛県「微地形図（CS立体図）」](https://www.geospatial.jp/ckan/dataset/csmap_ehime) | [高知県「微地形図（CS立体図）」](https://www.geospatial.jp/ckan/dataset/csmap_kochi) |
| タイル | `https://rinya-ehime.geospatial.jp/tile/rinya/2024/csmap_Ehime/{z}/{x}/{-y}.png`（TMS） | `https://rinya-kochi.geospatial.jp/2023/rinya/tile/csmap/{z}/{x}/{y}.png` |
| 元データ | 平成30年度 林野庁 航空レーザ計測（0.5m） | 平成30年度 林野庁 航空レーザ計測 |
| 出典表記 | 愛媛県森林資源データ（2018年計測） | 高知県森林資源データ（2018年計測） |

- 利用条件：各県「航空レーザ計測に基づく森林資源データの利用規約」（CC BY 4.0 互換、商用可、出典記載が必要）
- どちらの配信もCORSヘッダを返さないため、アプリでは「画像として表示・端末保存は可、ZIP書き出しは不可」として扱っています

## 出典
- CS立体図：愛媛県森林資源データ（2018年計測）、高知県森林資源データ（2018年計測）（G空間情報センター）
- 地理院タイル（国土地理院）
- 地質図：産総研地質調査総合センター「20万分の1日本シームレス地質図V2」（CC BY 4.0）
- 植生図：環境省生物多様性センター「現存植生図2024」
- 旧市町村界：歴史的行政区域データセットβ版（CODH）
- 筆ポリゴン：農林水産省「筆ポリゴンデータ（2022年度公開）」（農研機構 FlatGeobuf版）
- 人口：総務省統計局 国勢調査 地域メッシュ統計（e-Stat, 令和2年 500m）
